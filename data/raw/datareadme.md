# Raw Data

This folder holds the original, unprocessed dataset files. Contents are excluded from git via `.gitignore` due to size — only this README and `.gitkeep` are tracked.

## CityFlow Dataset 
- Access: https://www.aicitychallenge.org/ai-city-challenge-dataset-access/
- Paper: https://openaccess.thecvf.com/content_CVPR_2019/papers/Tang_CityFlow_A_City-Scale_Benchmark_for_Multi-Target_Multi-Camera_Vehicle_Tracking_and_CVPR_2019_paper.pdf
- The specific dataset used will be the **2022 Track 1: City-Scale Multi-Camera Vehicle Tracking** : https://www.aicitychallenge.org/2022-track1-download/
